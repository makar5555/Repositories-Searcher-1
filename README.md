# Repositories Searcher

Repositories Searcher це невеликий веб-застосунок в якому ти вставляєш посилання на профіль GitHub або нікнейм і отримуєш зручний список усіх його публічних репозиторіїв.


## Обмеження

- **Ліміт GitHub API** — без токена доступно близько **60 запитів на годину з однієї IP-адреси**. Один пошук використовує мінімум 2 запити. Після вичерпання ліміту застосунок покаже відповідне повідомлення.
- **Максимум 1000 репозиторіїв** на користувача (10 сторінок × 100).
- Показуються лише **публічні** репозиторії.
- Потрібне інтернет-з'єднання (API та шрифт Google Fonts).

## Технології

- HTML, CSS (змінні, `clamp()`, `prefers-color-scheme`), чистий JavaScript (`fetch`, `async/await`, `URL`, `URLSearchParams`)
- Шрифт [Bricolage Grotesque](https://fonts.google.com/specimen/Bricolage+Grotesque) через Google Fonts (із системним запасним шрифтом)
